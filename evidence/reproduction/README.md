## 配置

三个运行共用 Qwen3-8B 求解器与审核器、Qwen3.5-9B 选择器、Qwen3-Embedding-8B 嵌入模型及数学 two-pool 指标池。拓扑为 AutoGen 动态 SelectorGroupChat，`math_team_variant=verifier`；`max_turns=7` 计入初始用户消息；先检索 20 个指标，再选 1–5 个；批量审核，`pass_rate=0.6`；修正预算 3；不锁定首次指标，不使用 cheap precheck。四月题目并发 32，七月并发 50。详细配置与运行时间记录在 `summary.json`。

## 与论文版本的对应

[AgentDropoutV2 v1](https://arxiv.org/html/2602.23258v1) Table 1 的 Retrieved Indicators 行为 GSM8K 91.74%、MATH-500 78.40%。该版本使用 GPT-4.1-mini 选择器、直接 top-5 指标和零容忍审核。这里归档的四月主配置使用 Qwen3.5-9B 选择器和上述检索、筛选及通过率设置，与后续 Dynamic-MAS + ADv2 数学主表相对应。因此报告应同时列出版本和设置，比较相同归档主配置的独立重复时使用 91.66% 与 91.96%。
